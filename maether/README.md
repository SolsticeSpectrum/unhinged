# mAether
Server-side Fabric + Polymer port of [The Aether](https://github.com/The-Aether-Team/The-Aether) for vanilla 26.3 clients (Project Kestrel).
Code LGPL-3.0; assets All Rights Reserved, used with permission **non-commercially only** (see `NOTICE`, `docs/PERMISSION.md`). Status: `docs/PORT_REPORT.md`.
Pack hosting: use Polymer autohost (`kestrel:upload` from `kestrel-pack-upload`). Requires Java 25.
